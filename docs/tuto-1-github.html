Générateur de signature e-mail VoltR · Tuto 1

Héberger le générateur sur votre propre compte GitHub

Environ 15 minutes · gratuit · aucune connaissance technique requise

Ce que vous obtenezVotre propre adresse web pour le générateur, par exemple https://votre-identifiant.github.io/signature-voltr/
Les imagesHébergées automatiquement au même endroit, sans aucun réglage.
Ce qu'il vous fautLa pièce jointe VoltR-signature-projet.zip et Chrome ou Edge.
Pourquoi cette méthode est recommandéeC'est la solution la plus fiable : GitHub Pages est prévu pour publier des pages et des images. Les signatures fonctionnent dans toutes les messageries, et l'outil trouve ses images tout seul.

1Créer un compte GitHub

  1. Allez sur https://github.com/signup.
  2. Utilisez de préférence une adresse e-mail professionnelle de votre société.
  3. Choisissez l'identifiant (username) avec soin : il fera partie de l'adresse du générateur (https://identifiant.github.io/…). Préférez le nom de la société, en minuscules et sans espace.
  4. Validez l'e-mail de confirmation reçu, puis connectez-vous.

2Créer le dépôt (l'espace qui contiendra les fichiers)

  1. En haut à droite, cliquez sur + puis New repository.
  2. Repository name : signature-voltr (minuscules, avec un tiret). Ce nom fera aussi partie de l'adresse.
  3. Cochez Public. C'est obligatoire pour la publication gratuite, et le générateur ne contient aucune donnée confidentielle.
  4. Ne cochez rien d'autre (pas de README, pas de .gitignore, pas de licence).
  5. Cliquez sur Create repository.

3Déposer les fichiers

  1. Sur votre ordinateur, décompressez VoltR-signature-projet.zip : double-clic sur Mac, clic droit › Extraire tout… sur Windows. Vous obtenez un dossier VoltR-signature-projet.
  2. Sur la page de votre nouveau dépôt (encore vide), cliquez sur le lien uploading an existing file, dans la phrase « …or upload an existing file ».
  3. Ouvrez le dossier VoltR-signature-projet, sélectionnez tout son contenu (Ctrl+A sur Windows, ⌘+A sur Mac) et glissez-le dans la zone de la page GitHub. Le contenu comprend index.html, README.md et les dossiers assets, brand, docs et tools.
  4. Attendez que la liste des fichiers s'affiche, puis cliquez sur le bouton vert Commit changes en bas de page.
Vérification importanteSur la page du dépôt, index.html et le dossier assets doivent apparaître directement dans la liste, et non à l'intérieur d'un dossier VoltR-signature-projet. Si c'est le cas, vous avez glissé le dossier au lieu de son contenu. Supprimez le dépôt (Settings › tout en bas Delete this repository) et recommencez les étapes 2 et 3.

4Publier le site (GitHub Pages)

  1. Dans le dépôt, cliquez sur l'onglet Settings (roue dentée), puis sur Pages dans le menu de gauche.
  2. Section Build and deployment, champ Source : choisissez Deploy from a branch.
  3. Champ Branch : choisissez main dans le premier menu et laissez / (root) dans le second. Cliquez sur Save.
  4. Attendez 1 à 3 minutes, puis rechargez la page. Un encadré doit afficher « Your site is live at https://votre-identifiant.github.io/signature-voltr/ ».

5Vérifier que tout fonctionne

  • https://votre-identifiant.github.io/signature-voltr/ affiche le générateur.
  • https://votre-identifiant.github.io/signature-voltr/assets/signature-block.png affiche le bloc violet VoltR.
  • En bas du générateur, Paramètres avancés indique « ✓ Images accessibles en ligne » avec le mode Automatique.

6Distribuer le générateur à vos clients

Deux possibilités, que vous pouvez combiner :

MéthodeComment
A · Le lien web (recommandé)Envoyez simplement l'adresse https://votre-identifiant.github.io/signature-voltr/. Chaque personne l'ouvre, remplit ses informations, clique sur Générer vos signatures et suit le guide de sa messagerie.
B · Un fichier hors ligneSur votre site : Paramètres avancés › Télécharger le générateur configuré (.html). Le fichier Generateur-signature-VoltR.html s'ouvre d'un double-clic et utilise les images de votre site. Vous pouvez l'envoyer par e-mail.

7Si des signatures ont déjà été installées avec un autre hébergement

À faire une seule foisUne signature garde l'adresse des images au moment où elle a été créée. Les personnes qui ont installé leur signature avec une autre version du générateur doivent la regénérer depuis votre site et la réinstaller (quelques minutes, même guide). Sinon, le logo disparaîtra de leurs e-mails le jour où l'ancien hébergement sera supprimé.

Entretien courant

BesoinComment faire
Remplacer une image (ex. nouveau logo)Dans le dépôt, ouvrez le dossier assets › Add file › Upload files. Déposez le nouveau fichier avec exactement le même nom (signature-block.png ou linkedin.png) › Commit changes. Toutes les signatures existantes se mettent à jour, car l'adresse ne change pas. Taille attendue : 448 × 350 px pour le bloc, 48 × 48 px pour l'icône.
Modifier un fichierCliquez sur le fichier dans le dépôt › icône crayon (Edit) › modifiez › Commit changes. La mise en ligne se fait automatiquement en 1 à 2 minutes.
À éviter absolumentRenommer le dépôt, changer d'identifiant GitHub, repasser le dépôt en privé ou supprimer le dossier assets. Chacune de ces actions change ou coupe l'adresse des images et casse les signatures déjà installées.

En cas de souci

SymptômeSolution
Erreur 404 juste après l'activationPatientez 5 minutes : la première publication peut être lente.
Le menu Branch ne propose pas mainLes fichiers n'ont pas été enregistrés : refaites l'étape 3, jusqu'au bouton Commit changes.
GitHub demande un abonnement pour PagesLe dépôt est privé : Settings › General › tout en bas Change visibility › Public.
Le logo n'apparaît pas dans un e-mail reçuBeaucoup de messageries (Outlook notamment) bloquent les images tant que le destinataire n'a pas cliqué sur « Télécharger les images ». C'est normal : vérifiez avec une autre adresse.
